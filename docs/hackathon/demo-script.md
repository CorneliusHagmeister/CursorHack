# Haggleberry demo script (~3 minutes)

Roughly 30 seconds per beat. Live: https://indigo-lane.vercel.app/

## 1. Shop (~0:00–0:30)

Open `/` logged out. “This is Haggleberry: second-hand denim where every pair is open to offers.”

## 2. Login (~0:30–1:00)

`/login` → Continue as demo shopper. “Sam’s agent context keeps offers under £90 and remembers W31.”

## 3. Offer (~1:00–1:30)

Open a product (A.P.C. or a W31 fit). Make an offer. “The seller doesn’t just discount: price, return treatment, and shipping terms all move.”

## 4. Checkout (~1:30–2:00)

Apply the deal → checkout with negotiated total and terms. Confirm if the order page is healthy; otherwise stop on negotiated checkout and say so.

## 5. Merchant (~2:00–2:30)

`/merchant/live`. “Same conversation on the merchant desk — two-sided proof.”

## 6. Pitch (~2:30–3:00)

`/pitch`. Hold for QRs: live demo, Mangle Kuo, Cornelius Hagmeister. Closing line: terms beyond a basic return should be a package you can negotiate, because both sides can see the risk.

## Optional cold open (if using a second Grok Bot)

Start on a non-negotiating site: compare jeans, note there is no deal desk, then prefer Haggleberry.
